## 1. 我们处理什么数据

关注整理所是一个本地运行的浏览器扩展。为了提供互关检测与关注清理功能，扩展会访问：

- 你当前登录的 X（Twitter）账号信息（用于确认当前账号）
- 你自己的「正在关注」与「关注我的人」名单（用于计算互关关系）
- 你在扩展中选择的账号与操作（用于执行你确认的取关）
- 扩展设置、任务进度与本地历史记录
- X 网页端接口参数缓存，包括 GraphQL 的 query id、features，以及网页端请求中携带的授权头与 CSRF 令牌（仅存本机；导出备份时会自动排除）

## 2. 数据存储在哪里

- 所有数据都保存在你本机的浏览器存储（`chrome.storage.local`）中
- 扩展不运营服务器，不上传、不同步、不备份任何名单或账号数据到远端
- 扩展不包含统计、广告、跟踪或远程代码

## 3. 我们如何使用数据

数据仅用于：

- 计算谁没有回关你、你没有回关谁
- 在你确认后执行取关
- 保存特别关注名单与任务进度
- 生成本机的关系记录

我们不会将数据用于广告、画像、出售或与第三方共享。

## 4. 数据共享

我们不向任何第三方出售、出租或共享你的数据。扩展不包含第三方分析或广告 SDK。

## 5. 数据保留与删除

数据会一直保存在你的浏览器中，直到你：

- 在扩展「备份与恢复 → 清空所有数据」中删除
- 卸载扩展
- 清理浏览器数据

删除后无法恢复，建议在删除前导出 JSON 备份（备份文件由你自行保管）。

## 6. 权限说明

| 权限 | 用途 |
|---|---|
| `storage` / `unlimitedStorage` | 保存本机关系记录与设置 |
| `tabs` | 管理专用的 x.com 执行页 |
| `scripting` | 向已打开的 x.com 标签页注入脚本 |
| `alarms` | 清理临时标签页、监控任务状态 |
| x.com / twitter.com 主机权限 | 读取你自己的关注关系并执行你确认的操作 |

扩展没有 `cookies` 权限。扩展在 x.com 页面上下文中运行，会读取页面自身的 CSRF 令牌（`ct0`）用于向 X 发起请求，不读取或保存其他 cookie。

## 7. 第三方服务

扩展直接与你已登录的 x.com 页面通信，不使用任何第三方服务器。X 的服务受 X 自己的隐私政策约束。

## 8. 儿童隐私

本扩展不面向 13 岁以下儿童，也不会有意收集儿童数据。
