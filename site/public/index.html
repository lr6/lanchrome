把关注理清楚，
把时间留给值得的人。

关注整理所（TidyFollows）检测你在 X 上的互关关系，找出没有回关你的人， 在你勾选并确认后逐个清理。账号、名单和任务记录只保存在本机浏览器。

查看隐私政策 使用说明与支持

它做什么

只处理你自己的关注关系，所有清理动作都需要你逐条确认。

互关检测

看清三类关系

读取你自己的「正在关注」与「关注我的人」名单，再用接口精确核对，分成互关、未回关我、我未回关。

用户确认

勾选后才清理

先预览名单，再勾选要清理的账号，二次确认后逐个执行。取关间隔固定为 4–8 秒随机，可随时停止。

特别关注

想留下的人不会被碰

把重要账号加入特别关注，批量清理时自动跳过。永远优先于任何批量操作。

本地数据

随时备份、随时删除

记录保存在本机浏览器，可导出 JSON 备份；卸载扩展或在扩展内清空数据即可删除。

怎么用

首次建议先检测 1,000 人，确认名单后再清理。

  1. 连接 X 账号 在浏览器里登录 x.com，打开扩展，点击「连接 X 账号」。扩展使用你当前的网页会话，不需要 X API Key。
  2. 开始检测 选择 1,000 / 3,000 / 全部。首次检测会短暂打开两个后台标签页，用于获取 X 网页端的接口参数。
  3. 保护想留下的人 在「关系名单」里查看结果，把重要的人加入「特别关注」。
  4. 勾选、预览、确认 选中要清理的账号，点「批量取关」，在预览里确认名单。取关逐条执行，随时可以停止，中断后可以继续。

隐私优先

没有自建服务器，没有统计、广告或远程代码。

不上传名单

关注关系、账号信息和任务进度只写入本机 chrome.storage.local，不会发送到我们的服务器。

不收集统计

扩展不包含分析 SDK、广告或跟踪代码，也不读取与功能无关的浏览记录。

权限最小化

只申请保存数据、管理专用 x.com 执行页和定时清理所需的权限，不含 cookies 权限。

完整说明数据处理方式、保留期限和删除方式见 隐私政策。

使用前请了解

不是 X 官方产品

本扩展与 X Corp. 没有隶属关系。请遵守 X 的服务条款和当地法律法规，合理控制操作频率。

依赖 X 网页端接口

X 更新接口后，检测或取关可能暂时失效。可在「设置 → 刷新接口参数」重试，或联系支持。

存在账号风险

短时间大量取关可能触发限流或临时限制。建议分批进行，不要频繁执行。

先备份再操作

清理浏览器数据、卸载扩展或换电脑前，请先在「备份与恢复」导出 JSON。

安装方式本扩展通过 Chrome 应用商店分发。上架后在商店搜索「关注整理所」即可安装，也可以在 支持页查看手动安装步骤。
