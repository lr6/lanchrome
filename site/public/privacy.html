1. 我们处理哪些数据

关注整理所是一个在本机浏览器中运行的扩展。为了提供互关检测与关注整理功能，扩展会访问和处理：

  • 你当前登录的 X 账号信息，例如账号 ID、用户名和显示名称（用于确认当前账号）；
  • 你自己的「正在关注」与「关注我的人」名单，以及这些账号的公开资料（用于计算互关关系）；
  • 你在扩展中勾选、保护和执行取关的账号记录（用于执行你确认的操作和展示历史）；
  • 扩展设置、任务进度、扫描结果与本地历史记录；
  • X 网页端接口参数缓存，包括 GraphQL 的 query id、features，以及网页端请求中携带的授权头与 CSRF 令牌。

这些数据均来自你自己已登录的 x.com 页面。扩展不读取与关注关系无关的浏览记录、私信、推文内容或其他网站的数据。

2. 数据存储在哪里

  • 所有数据都保存在你本机的浏览器存储（chrome.storage.local）中。
  • 扩展不运营服务器，不上传、不同步、不备份任何名单、账号或任务数据到远端。
  • 扩展不包含统计、广告、跟踪或远程加载的代码。
  • 导出的 JSON 备份只保存在你的电脑上，由你自行保管或分享。备份文件不包含接口参数缓存中的请求头。

3. 我们如何使用数据

数据仅用于：

  • 计算谁没有回关你、你没有回关谁、谁与你互相关注；
  • 在你勾选并二次确认后，向 X 发起对应的取关请求；
  • 保存特别关注名单，并在批量操作时跳过这些账号；
  • 保存任务进度，使中断后的任务可以继续；
  • 在你本机生成关系记录与历史。

我们不会将数据用于广告、用户画像、出售或与第三方共享。

4. 数据共享

我们不向任何第三方出售、出租或共享你的数据。扩展不包含第三方分析或广告 SDK。扩展只会直接与你已登录的 X 网页端通信，以读取你自己的关注关系并执行你确认的操作。

5. 数据保留与删除

数据会一直保存在你的浏览器中，直到你：

  • 在扩展的「备份与恢复 → 清空所有数据」中删除；
  • 卸载扩展；
  • 清除浏览器数据。

删除后无法恢复。建议在删除前先导出 JSON 备份，并把备份文件保存在你自己的安全位置。接口参数缓存也可以在「设置」中单独清除。

6. 权限说明

权限 用途
storage / unlimitedStorage 在本机保存关系记录、特别关注、任务进度与设置；关注名单较大时避免超出默认存储额度。
tabs 打开、检查并关闭扩展专用的 x.com 执行标签页。
scripting 向已经打开的 x.com 标签页补注入内容脚本，用于恢复任务。
alarms 定时清理临时标签页、监控任务状态。
https://x.com/*、https://twitter.com/* 读取你自己的关注关系，并在你确认后执行取关。

扩展没有申请 cookies 权限。扩展在 x.com 页面上下文中运行，复用页面自身已有的登录会话和请求头来与 X 通信；这些请求头仅在本机内存和本地存储中使用，不会发送给任何第三方。具体来说，扩展会读取页面自身的 CSRF 令牌（ct0）用于向 X 发起请求，不读取或保存其他 cookie。

7. 第三方服务

扩展直接与你已登录的 x.com 页面通信，不使用任何第三方服务器、CDN 或统计服务。你在 X 上的数据处理同时受 X 自己的隐私政策约束。

8. 儿童隐私

本扩展不面向 13 岁以下儿童，也不会有意收集儿童数据。

9. 免责声明

本扩展不是 X Corp. 的官方产品，与 X 无隶属关系。X 的网页接口可能变化，扩展功能可能因此暂时失效。请遵守 X 的服务条款与当地法律法规，并自行承担使用批量取关功能可能带来的账号风险。

10. 政策更新

如果本政策发生变更，我们会更新本页面的「生效日期」。重大变更会在扩展更新说明中提示。继续使用扩展即表示你接受更新后的政策。

11. 联系我们

如有隐私相关问题、数据删除请求或安全报告，请联系 support@1475369.xyz。我们通常会在 3 个工作日内回复。

English Summary

TidyFollows is a Chrome extension that runs entirely in your browser. It reads your own X (Twitter) Following and Followers lists, computes mutual-follow relationships, and unfollows accounts only after you explicitly select and confirm them.

  • Data processed: your X account identity, your own follow relationships, the accounts you select, and local settings/task progress. API request metadata (authorization header and CSRF token) captured from your own x.com session is cached locally.
  • Storage: everything is stored locally in chrome.storage.local. We operate no server.
  • No collection or sharing: no analytics, advertising, tracking, remote code, or third-party services. Nothing is uploaded, sold, or shared.
  • Deletion: use “Clear all data” in the extension, uninstall it, or clear your browser data. Exported backups do not contain cached request headers.
