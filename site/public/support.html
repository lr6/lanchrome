支持与故障排查

先跑一次「设置 → 运行自检」，多数问题可以在那里定位。

联系支持

邮箱：support@1475369.xyz，通常 3 个工作日内回复。为了更快定位问题，请附上：

  • 扩展版本号（设置页底部显示）；
  • Chrome 版本与操作系统；

常见问题

连接 X 账号失败

确认当前浏览器已登录 x.com，并且登录状态没有过期。必要时重新登录后再点「连接 X 账号」。

扩展不会索要密码，也不会读取你的登录凭据，只复用浏览器里已有的网页会话。

提示「未能获取 X 接口参数」

在「设置 → 接口参数」点「刷新接口参数」，或手动打开一次自己的「正在关注」页面，再重新检测。

接口参数会缓存 18 小时，过期后会自动重新获取。

读取关注第一页返回 403 / 404

通常是接口参数或 transaction-id 过期。点「刷新接口参数」后重试。如果仍然失败，可能是 X 更新了网页端接口，请把自检结果发给支持。

读取名单返回 429（限流）

说明当前请求被 X 限流。扩展会自动读取响应里的恢复时间并等待；自检结果里也会显示恢复时间。等限流结束后再重试，期间不要频繁刷新。

「我未回关」显示为 — 或结果不完整

粉丝名单接口可能不可用，或者只读取到了第一页。扩展会继续用互关核对完成「未回关我」的检测；「我未回关」则标记为不可用或部分结果。

这不影响取关已有名单里的人，但统计只代表本次扫描范围。

检测解析到 0 人

X 可能返回了登录页或空数据。确认账号状态正常，刷新接口参数后再试。如果你确实没有关注任何人，也会得到 0 人的结果。

自检提示写接口探测 404

自检会用一个无效的用户 ID 探测取关接口，不会改动任何账号。返回 404 只表示这个端点可能已变更或废弃，并不代表你的账号有问题。

在正式批量取关前，建议先对少量账号操作一次，确认实际行为。如果确实失败，请把自检结果发给支持。

任务中断了，怎么继续？

任务运行期间不要关闭或刷新专用执行页，也不要关闭浏览器。中断后打开控制台，点「继续任务」即可从上次进度续跑。

浏览器重启后，旧任务会被标记为可继续，而不是继续在后台静默执行。

会把我的关注全部自动取关吗？

不会。检测只读取关系，不会执行任何写操作。取关必须由你勾选账号、点击「批量取关」并在预览里二次确认，之后才会逐个执行。特别关注的人始终跳过。

数据保存在哪里？怎么删除？

全部保存在本机浏览器的 chrome.storage.local，不会上传到服务器。删除方式：扩展内「备份与恢复 → 清空所有数据」、卸载扩展，或清除浏览器数据。

删除前建议先导出 JSON 备份。详见隐私政策。

怎么手动安装（开发者模式）？
  1. 下载并解压扩展目录，确认 manifest.json 就在这一层目录里。
  2. 打开 chrome://extensions，右上角开启「开发者模式」。
  3. 点击「加载已解压的扩展程序」，选择包含 manifest.json 的目录。
  4. 登录 x.com，点击扩展图标，选择「连接 X 账号」。

更新时用新文件替换原目录，然后在扩展管理页点「重新加载」。不要先卸载，以免丢失本机数据。

为什么需要这些权限？

扩展需要在本机保存关系记录（storage）、打开专用 x.com 执行页（tabs）、补注入脚本（scripting）、定时清理临时标签页（alarms），并访问 x.com / twitter.com 读取你自己的关注关系。扩展没有 cookies 权限，也没有任何统计或广告代码。

逐项说明见隐私政策的权限部分。
